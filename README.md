# 🍮 Pudim Cremoso

Um site desenvolvido para apresentar a história, curiosidades e características do **pudim**, uma das sobremesas mais tradicionais e apreciadas.

## 📖 Sobre o projeto

O **Pudim Cremoso** é um projeto web criado com o objetivo de apresentar informações sobre essa sobremesa de forma simples, elegante e visualmente agradável.

O site possui uma identidade visual inspirada em tons escuros, dourados e caramelizados, combinando com o tema do pudim.

## ✨ Funcionalidades

* 🏠 **Página Inicial** — apresentação do Pudim Cremoso.
* 📜 **História** — informações sobre a história e evolução do pudim.
* 💡 **Curiosidades** — fatos interessantes sobre a sobremesa.
* 🍮 **Imagens** — apresentação visual do pudim.
* 📱 **Layout responsivo** — adaptação para diferentes tamanhos de tela.
* ✨ **Animações** — efeitos de entrada dos elementos durante a navegação.

## 🚀 Como executar o projeto

1. Clone o repositório:

```bash
git clone URL_DO_SEU_REPOSITORIO
```

2. Entre na pasta:

```bash
cd Site-Pudim
```

3. Abra o arquivo:

```text
index.html
```

Também é possível utilizar o **Live Server** no Visual Studio Code para executar o projeto localmente.
